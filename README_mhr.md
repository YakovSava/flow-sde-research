> гипотеза, протокол але план; ончычсо паша гыч цифрвлак тугак палемдалтыныт.

Flow-matching модельвлаклан SDE-сэмплерыште стохастичность вийым (`eta`) кӱчык NFE бюджет дене
(6–15 ошкыл) кучымо нерген шымлымаш.

Тиде кок ончычсо пашам шуйышо паша. Кок пашат
[adaptive-step-samplers](https://github.com/YakovSava/adaptive-step-samplers) репозиторийыште
савыктыме ([DOI](https://doi.org/10.5281/zenodo.23529356)):

1. Предиктор да корректор ойыртем гыч налме мӱндыр локальный йоҥылыш оценке, ошкыл кугытым
   адаптивный ыштымаш верч.
2. SA-Solver стохастичность вийым почмо, тыгак йоҥылыш дене шумым кучымаш (`response` ≠ 0) —
   тиде отрицательный результат лие.

Тиде репозиторийыште вес механизмым тергат: траекторийын локальный кривизны дене шумым
ошкылвлак коклаште шаралтымо.

## Мотивация

ComfyUI-ште `sa_solver` стохастичность вийым ик константа `eta = 1.0` дене, 20–80 % фиксироватлыме
окна кӧргыштӧ кучен. Ончычсо паша `eta`-м почо да `eta = 1.6–1.8` текстурым макрогеометрий дене
налме манын ончыкто; `1.8` деч вара «обмен курс» чот волен. Константа да окна кид дене ойыралтыт
да траекторий могай лиймым ок ужыт.

Шумым адаптивный ыштыме ончычсо попытке тудым мӱндыр предиктор–корректор йоҥылыш оценке
(`pc_error`) дене тӧрыш кучыш. Чыла тестыште тудо `eta`-м ик гай среднийын изиэмдымаш дене
шум кугытыште ик гай лие. Тиде тыге ойла: шумын *кугыт* кӱлеш ыле, а йоҥылышлан пропорциональ
кучымаш нимом ок эше пу.

## Гипотеза

Почмо йодыш вес: **шум мыняр шуко огыл, а траекторий кушто пурталтеш.** Скорость пӱтырыш
жёсткий верыште (кугу кривизна) пурталтыше шум геометрий йоҥылышыш савырналтын кертеш, а гладкий
верыште тудак шум текстурыш савырналтеш. Тыге гын, ик гай бюджет годым шумын фиксироватлыме
бюджетым ошкылвлак коклаште локальный кривизна дене шарымаш равномерный `eta`-м деч сайрак
геометрий/текстура компромиссым пуа.

Тиде `response` ≠ 0 деч вес механизм да тиде пашаш ончыч тергалтын огыл (результатвлак ӱлнӧ).
Знак (шуко шум жёсткий ошкылыште але гладкий ошкылыште) ончыч паледыме огыл ыле да, тудым
эксперимент дене ойыраш кӱлеш ыле.

## Метод

Кажне `i` ошкылыште сэмплер модельым шотлен, `d_i = (x_i - denoised_i) / sigma_i` производный
тыште. Локальный кривизна:

```
kappa_i = rms(d_i - d_{i-1}) / |sigma_i - sigma_{i-1}|
```

Тиде — ончычсо пашан Trajectory Probe возен кодыш кугыт да сетьым **эше ик гана ок шотло**. `i`
гыч `i+1` ошкыл верч шум мощность:

```
tau_i^2 = eta_bar^2 * w_i * c_i      шум окнашке, 0 — тудын ӧрдыжтӧ
w_i     = clamp((kappa_i / reference_i)^exponent, 1/spread, spread)
```

Тышке `reference_i` — ончычсо кривизнан скользящий средний, `eta_bar` — номинальный вий, `c_i` —
бюджет кучымо коэффициент (ӱлнӧ). Кучымаш причинный: `i` ошкылыште шотлымо деч вара пале лийше
информацийым гына налеш.

### Кӱлешан контроль: ик гай шум бюджет

Ӱлнӧ ончыктымо отрицательный результат *мыняр шуко* да *кушто* ик ӱш ыле. Тидым ок ыште манын,
кажне адаптивный запуск равномерный `eta` дене, **ик гай интегральный шум бюджет** дене
таҥастарыме, сӧрал, окнаште `sum(tau_i^2 * h_i)` ик гай (тышке `h_i` — log-SNR ошкыл). Лач ик
гай бюджет годым пайда гына шарымаш гипотезым пеҥгыдемда.

### Таҥастарыме вариантвлак

Чыла вариант — ик `Flow-SDE Sampler` нодын настройкывлак (`signal`, `exponent`,
`conserve_budget`); ончо [Реализаций](#реализаций).

| Вариант | Настройкывлак |
| --- | --- |
| `sa_solver` | ComfyUI базовый вариант; `eta = 1.0`, `exponent = 0` годым бит-бит ик гай |
| `uniform` | `exponent = 0`, `eta` 1.6–1.8 (ончычсо пашаште ойырыме база) |
| `uniform-matched` | `exponent = 0`, `eta` тыге ойырыме: `eta^2 * sum(h)` адаптивный запускын чын бюджетше дене ик гай. `conserve_budget` пурталтыме годым тиде — ик `eta` дене `uniform` |
| `curvature-online` | `signal = curvature`, `exponent > 0` (жёсткий ошкылвлакыште шуко шум) |
| `curvature-online, inverted` | `signal = curvature`, `exponent < 0` (гладкий ошкылвлакыште шуко шум) |
| `pc-error-online` | `signal = pc_error`, ончычсо отрицательный результат дене таҥастарыме верч |
| `static-profile` | Кривизнан средний профиль гыч фиксироватлыме неравномерный `tau` график, чыла сэмплылан ик гай. **Эше ыштыме огыл** |

`static-profile` *онлайн* адаптаций чынак кӱлеш мо але фиксироватлыме неравномерный график
тыйымак пуэн кертеш мо — тидым ойыра. Ончычсо дисперсий декомпозиций (ончычсо репозиторийыште
`analyze_dumps.py`) сигналын могай ужашыже ошкыл номер дене ойыралтын, могай — конкрет сэмпль
дене, да онлайн кучымашлан мыняр пош кодеш — тидым ончыкта.

## Реализаций

```
noise_allocation.py   NoiseAllocator: curvature / pc_error сигнал гыч ошкылеш tau
sampler.py            sample_flow_sde: аллокатор tau дене SA-Solver цикл
nodes.py              ComfyUI нода "Flow-SDE Sampler"
metrics.py            геометрий / текстура метрикывлак, граница деч пайда, bootstrap
profiles.py           кажне модель верч граф, разрешений, cfg, метрике пулинг
run_experiment.py     ComfyUI-м HTTP API дене виктара да таҥастарымашым луктын пуа
export_results.py     чыла сэмпль метрике да ушнымо таблицым results/ папкашке возаш
build_survey.py       айдеме опрос верч сӱретвлак да вашмут ключым survey/ папкашке погаш
results/              samples.csv (сӱретлан ик строка) да summary.csv (модельлан, NFE, вариантлан ик строка)
tests/                модульный тествлак (pytest)
```

Пурташ: `ComfyUI/custom_nodes/` папкашке клонироватлаш да ComfyUI-м вес гана ыштен пуаш. Лишне
зависимостьвлак уке. Нода `sampling/custom_sampling/flow_sde` кӧргыштӧ.

| Параметр | Мут |
| --- | --- |
| `eta` | Номинальный стохастичность вий `eta_bar` |
| `stochastic_start`, `stochastic_end` | Шум окна, `sa_solver` гай (кӧра 0.2–0.8) |
| `signal` | `curvature` (мӱндыр, лишыл производныйвлак гыч) але `pc_error` (мӱндыр, предиктор да корректор ойыртем) |
| `exponent` | `signal / running_reference`-ым ӱдырыме степень. `0` — адаптацийым чара; знак шуко шум жёсткий але гладкий ошкылвлакыште лиймым ойыра |
| `conserve_budget` | Вара ошкылвлакым тыге масштабироватлаш, окнаште `sum(tau_i^2 * h_i)` `eta^2 * sum(h_i)` дене ик гай лийже. Кодшо ужашым окнан мучаш ошкылже налеш |
| `spread` | Вес `[1/spread, spread]` дене чекланалтеш |
| `smoothing` | Скользящий опорный кугытын EMA коэффициентше |
| `tau_max` | `tau`-лан кӱкшӧ чек (отсечений дене бюджетын ужашыже кодын кертеш) |

Вес шум мощность `tau^2`-ыш, а `tau`-ыш огыл, мыйын бюджет `tau^2 * h` дене шотлалтеш. Шот —
кажне ошкыл верч раш 1 NFE.

### Тествлак

```
venv/Scripts/python.exe -m pytest custom_nodes/flow-sde-research/tests
```

ComfyUI тӱҥ папкаште ыштыме. Тествлак тыге тергат: `exponent = 0` годым 6, 10 да 15 ошкылыште
`sa_solver` дене бит-бит ик гай (кугу абсолютный ойыртем `0`); адаптивный запускыште NFE ошкыл
шот дене ик гай; бюджет кучыме запускын чын бюджетше равномерный дене ик гай; аллокатор
инвариантвлак (окна, границывлак, отсечений, степень знак). Сэмплер тествлак синтетический
flow-моделым кучат, тидлан нуно механизм чын ыштымым ончыктат да сӱрет сай лиймым нимом ок ойло.

### Эксперимент ыштыме

ComfyUI ыштыме годым (да `profiles.py`-ште модель, LoRA, текст энкодер да VAE лӱмвлакым шке
установкыланет келыштаре). `--model` профильым ойыра (кӧра `anima`, `flux3` але `moss`):

```
venv/Scripts/python.exe custom_nodes/flow-sde-research/run_experiment.py \
    --prompts flat face --seeds 42 1337 --budgets 10 --variants sa_solver uniform_e17 curv_p1
```

Латентвлак да сӱретвлак `output/flow_sde/` папкашке возалтыт (вес модельвлак верч
`output/flow_sde_flux3/` да `output/flow_sde_moss/`); пытыме заданийвлак ӧрдыжтӧ кодалтыт, тыге
чарныме запуск шуйалтеш. `--analyse-only` отчётым кодмо файлвлак гыч вес гана шотла, `--report
FILE` сэмпль метрикывлакым JSON дене кода.

Отчёт кажне вариант верч средний геометрийым, текстурым да 30 ошкыл конвергентный эталон дене
текстура ойыртемым пуа, тунамак **равномерный граница деч текстура пайдам**: вариантын
текстурыже да ик геометрийыште равномерный `eta`-ан сэмплер (`uniform_e14`, `uniform_e17`,
`uniform_e20`) пуымо текстура ойыртем (линейный интерполяций), (промпт, seed) пар дене 95 %
bootstrap доверительный интервал дене. `eta` кривой дене гына ошкылтыше вариант нуль налеш; сай
компромисс — нуль деч кӱкшӧ. Вариант геометрийже равномерный запускын диапазонышт ӧрдыжтӧ
лийме годым `n/a` палемдалтеш.

### Моделивлак коклаште

`pc_error` вариантвлаклан равномерный граница деч текстура пайда, вич бюджет (6, 8, 10, 12, 15 NFE)
дене шотлыме:

| Модель | `pce_m1` положительный / значимо положительный | `pce_p1` отрицательный / значимо отрицательный |
| --- | --- | --- |
| Anima | 2 / 1 | 2 / 0 |
| Flux 3 Klein | 5 / 5 | 5 / 5 |
| MOSS-Image | 5 / 1 | 4 / 4 |

(Кажне ячейка — вич бюджет гыч шотшо: ончыктыме знак дене точечный оценке / 95 % интервал тиде
могырыште нульым ок пурто.) Эффект ужалтыме верыште могыр ик гай, кугыт модель дене чот
вашталтеш, а Anima-ште тиде выборка кугытышто ужалтыде.

## Кокымшо цель

- **Вес flow-matching модельыш кусарымаш.** Flux 3 Klein верч ыштыме (ончо ӱлнӧ): эффект
  универсальный огыл. MOSS-Image (вес архитектур: 5 млрд параметрыш DiT, Qwen3.5-9B текст
  энкодер, ик FLUX.2 VAE гына ик гай) тунамак ыштыме; `pc_error` эффект могыр Flux 3 дене ик гай,
  но кугыт чот изирак.
- **Метрикывлакым айдеме ончымаш дене тергымаш.** Сӱрет набор да вашмут ключвлак ямдылыме (ончо
  [Айдеме опрос материалвлак](#айдеме-опрос-материалвлак)); вашмутвлак погалтыт да эше нимо
  анализироватлыме огыл. Тергымаш кок сӱрет гыч могай ИИ дене ыштыме семын койшо манме йодышым
  ышта, тыге шке геометрий да текстура метрикывлак айдеме ончымаш дене келшат мо манме тергалтеш,
  мыйын чыла количественный ойлымашвлак нуно ӱмбак шочыт. Flux 3 результат дене тиде — приоритет:
  йодыш — айдеме `pce_m1` текстура пайдам ужеш мо.

## Пале ойыртемвлак

- Кум модель, кок гыч int8 чекпойнт да ик `eta_bar`; Flux 3 профиль вес кок деч вес геометрий
  эталонжым кучен.
- Геометрий да текстура — латент пространствыште прокси, тергалтше перцептивный метрике огыл.
- `eta` кугемдымаш композицийымат вашталта, тидлан детерминированный эталон дене «геометрий»
  структурный вред да лийме вашталтышым ик ушен шога.

## Ончычсо репозиторий дене кылдалтыш

`sampler.py`-ште SA-Solver цикл `adaptive-step-samplers` репозиторий `sample_adaptive_sa` гыч
келыштарыме, йоҥылыш дене виктарыше контроллер `NoiseAllocator` дене вашталтыме. Trajectory
probe да анализ скриптвлак копироватлыме огыл да эксперимент раннер нунын деч ок шого: тудо
пытыме латентвлакым core `SaveLatent` нод дене кода.
