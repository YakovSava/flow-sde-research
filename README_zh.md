# Flow-SDE Research：随曲率自适应的随机性

[English](README.md) · [Русский](README_ru.md) · 中文

本文为译文。英文版（[README.md](README.md)）是权威版本；译文可能滞后，若两者不一致，以英文为准。

> **状态：初步。** 采样器已实现，通过单元测试，并在 ComfyUI 中验证可与 `sa_solver` 逐位一致。
> 已在三个模型上测量（Anima、Flux 3 Klein、MOSS-Image）。基于曲率的噪声分配在**任何一个模型上
> 都没有稳定效果**。基于误差的分配（`signal = pc_error`）在 Anima 上没有效果，在 Flux 3 上有
> 方向一致的效果，在 MOSS-Image 上是单边效应（符号错误会有损害，符号正确只有少量收益）。
> 参见[初步结果](#初步结果)。下文其余内容均为假设、协议或计划；引用自早期工作的数字已作标注。

研究在低 NFE 预算（6–15 步）下，如何控制 flow-matching 模型 SDE 采样器中随机性强度（`eta`）。

这是对两项早期工作的后续，二者均发表于
[adaptive-step-samplers](https://github.com/YakovSava/adaptive-step-samplers)
（[DOI](https://doi.org/10.5281/zenodo.23529356)）：

1. 利用预测器–校正器之差得到的免费局部误差估计，用于自适应步长。
2. 公开 SA-Solver 的随机强度，其中包括按误差驱动的噪声控制（`response` ≠ 0），结果为负面。

本仓库检验另一种机制：按轨迹局部曲率在各步之间分配噪声。

## 动机

ComfyUI 的 `sa_solver` 把随机强度固定为常数 `eta = 1.0`，并限定在固定的 20–80 % 窗口内。早期
工作开放了 `eta`，发现 `eta = 1.6–1.8` 以宏观几何为代价换取纹理，且超过 `1.8` 后“兑换率”急剧
下降。常数和窗口都靠手工选择，对轨迹实际在做什么毫无感知。

早期让噪声自适应的尝试，直接用免费的预测器–校正器误差估计（`pc_error`）来驱动。在所有测试
中，它在噪声范围内都与把 `eta` 平均降低同样幅度的做法相当。这说明起作用的是噪声的*大小*，
按误差比例控制并没有带来额外收益。

## 假设

未解决的问题不同：**不是噪声多少，而是噪声沿轨迹注入在何处。** 在速度场较“硬”（高曲率）处
加入的噪声可能被放大为几何误差，而在平滑处加入的同样噪声则可能转化为纹理。如果成立，
在相同预算下按局部曲率在各步之间重新分配固定的噪声预算，应当比均匀 `eta` 得到更好的几何/纹理
折中。

这是与 `response` ≠ 0 不同的机制，在本工作之前未被检验（结果见下文）。这种关系的符号（噪声多放
在硬步还是平滑步）事先未知，需要由实验来确定。

## 方法

在每一步 `i`，采样器已完成模型评估，并持有导数
`d_i = (x_i - denoised_i) / sigma_i`。局部曲率为

```
kappa_i = rms(d_i - d_{i-1}) / |sigma_i - sigma_{i-1}|
```

这正是早期工作中 Trajectory Probe 所记录的量，**无需额外的网络评估**。从 `i` 到 `i+1` 一步的
噪声功率为

```
tau_i^2 = eta_bar^2 * w_i * c_i      在噪声窗口内；窗口外为 0
w_i     = clamp((kappa_i / reference_i)^exponent, 1/spread, spread)
```

其中 `reference_i` 是过去曲率的滑动平均，`eta_bar` 是名义强度，`c_i` 是预算守恒因子（见下）。
该控制是因果的：只使用第 `i` 步评估之后可得的信息。

### 关键的对照：相同的噪声预算

上述负面结果把*多少*和*在哪里*混在了一起。为避免重蹈覆辙，每个自适应运行都与一个**积分噪声
预算相同**的均匀 `eta` 运行比较，例如在窗口内使 `sum(tau_i^2 * h_i)` 相等（`h_i` 为 log-SNR
步长）。只有在相同预算下的增益才能支持重新分配的假设。

### 对比的变体

所有变体都是同一个 `Flow-SDE Sampler` 节点的设置（`signal`、`exponent`、`conserve_budget`）；
见[实现](#实现)。

| 变体 | 设置 |
| --- | --- |
| `sa_solver` | ComfyUI 基线；在 `eta = 1.0`、`exponent = 0` 时逐位复现 |
| `uniform` | `exponent = 0`，`eta` 取 1.6–1.8（早期工作中调好的基线） |
| `uniform-matched` | `exponent = 0`，`eta` 的取值使 `eta^2 * sum(h)` 等于某次自适应运行的实际预算。开启 `conserve_budget` 时，这就是同一 `eta` 下的 `uniform` |
| `curvature-online` | `signal = curvature`，`exponent > 0`（硬步多加噪声） |
| `curvature-online, inverted` | `signal = curvature`，`exponent < 0`（平滑步多加噪声） |
| `pc-error-online` | `signal = pc_error`，用于与早期的负面结果对照 |
| `static-profile` | 由平均曲率剖面得到的、对所有样本固定的非均匀 `tau` 日程。**尚未实现** |

`static-profile` 用于分辨*在线*自适应是否真的重要，还是固定的非均匀日程就已能获得该效果。
早期的方差分解（早期仓库中的 `analyze_dumps.py`）衡量信号中有多少仅由步序号解释、有多少属于
样本特异行为，从而决定在线控制还有多大空间。

## 实现

```
noise_allocation.py   NoiseAllocator：根据 curvature / pc_error 信号逐步给出 tau
sampler.py            sample_flow_sde：由分配器驱动 tau 的 SA-Solver 循环
nodes.py              ComfyUI 节点 "Flow-SDE Sampler"
metrics.py            几何 / 纹理指标、相对前沿的优势、bootstrap
profiles.py           各模型的计算图、分辨率、cfg、指标池化
run_experiment.py     通过 HTTP API 驱动 ComfyUI 并输出比较结果
export_results.py     将所有逐样本指标和汇总表写入 results/
build_survey.py       在 survey/ 中生成人类研究的图像集和答案键
results/              samples.csv（每图一行）和 summary.csv（每个模型、NFE、变体一行）
tests/                单元测试（pytest）
```

安装：克隆到 `ComfyUI/custom_nodes/` 并重启 ComfyUI。无额外依赖。节点位于
`sampling/custom_sampling/flow_sde`。

| 参数 | 含义 |
| --- | --- |
| `eta` | 名义随机强度 `eta_bar` |
| `stochastic_start`、`stochastic_end` | 噪声窗口，与 `sa_solver` 相同（默认 0.2–0.8） |
| `signal` | `curvature`（免费，来自相邻导数）或 `pc_error`（免费，预测器–校正器之差） |
| `exponent` | 作用于 `signal / running_reference` 的幂。`0` 表示关闭自适应；符号决定噪声偏向硬步还是平滑步 |
| `conserve_budget` | 重新缩放后续各步，使窗口内的 `sum(tau_i^2 * h_i)` 等于 `eta^2 * sum(h_i)`。窗口最后一步吸收余量 |
| `spread` | 权重被限制在 `[1/spread, spread]` |
| `smoothing` | 滑动参考值的 EMA 系数 |
| `tau_max` | `tau` 的硬上限（截断可能使部分预算未被用掉） |

权重作用于噪声功率 `tau^2` 而非 `tau`，因为预算是以 `tau^2 * h` 度量的。成本恰好为每步 1 NFE。

### 测试

```
venv/Scripts/python.exe -m pytest custom_nodes/flow-sde-research/tests
```

在 ComfyUI 根目录运行。测试验证：`exponent = 0` 在 6、10、15 步时与 `sa_solver` 逐位一致
（最大绝对差 `0`）；自适应运行的 NFE 等于步数；预算守恒运行的实际预算等于均匀运行的预算；
以及分配器的不变量（窗口、边界、截断、指数符号）。采样器测试使用合成的 flow 模型，因此只
证明机制本身正确，对图像质量不说明任何问题。

### 运行实验

在 ComfyUI 已运行的情况下（并按你的安装修改 `profiles.py` 中的模型、LoRA、文本编码器和 VAE
名称）。`--model` 选择配置（默认 `anima`，也可用 `flux3` 或 `moss`）：

```
venv/Scripts/python.exe custom_nodes/flow-sde-research/run_experiment.py \
    --prompts flat face --seeds 42 1337 --budgets 10 --variants sa_solver uniform_e17 curv_p1
```

潜变量和图像写入 `output/flow_sde/`（其他模型为 `output/flow_sde_flux3/` 和
`output/flow_sde_moss/`）；已完成的任务会被跳过，因此中断的运行可以续跑。`--analyse-only`
根据已有文件重新计算报告，`--report FILE` 将逐样本指标保存为 JSON。

报告给出每个变体的平均几何、纹理，以及与收敛的 30 步参考之间的纹理差距，还有**相对均匀前沿的
纹理优势**：某变体的纹理与在相同几何下均匀 `eta` 采样器（`uniform_e14`、`uniform_e17`、
`uniform_e20`）应有的纹理之差（线性插值），并附基于（提示词，seed）配对的 95 % bootstrap 置信
区间。仅仅沿 `eta` 曲线移动的变体得分为零；更好的折中得分高于零。若变体的几何落在均匀运行的
范围之外，则报告为 `n/a`。

### 已保存的指标

`results/samples.csv` 每张生成图像一行（模型、ComfyUI 版本、变体、提示词、seed、NFE、几何、
纹理、纹理差距、几何参考类型）。`results/summary.csv` 给出按（模型、NFE、变体）的均值，以及
相对均匀前沿的纹理优势及其 95 % bootstrap 区间。两个文件均可由保存的潜变量用
`venv/Scripts/python.exe custom_nodes/flow-sde-research/export_results.py` 重新生成。CSV 中的
区间与 README 表格可能在最后一位有差异，因为 bootstrap 对配对的重采样顺序不同；点估计相同。
Anima 的行来自 ComfyUI 0.31.1，其余来自 0.42.5（`comfyui_version` 列）；Flux 3 的 `geometry`
列相对于相同预算的 `euler` 运行，其余两个模型则相对于 100 步运行。

在 RTX 5060（8 GB）、768×1024 下测得的成本：Flux 3 Klein 约每步 0.65 秒，Anima 和 MOSS-Image
约每步 0.9–1 秒。每个（提示词，seed）的 100 步几何参考（约 90 秒）和 30 步纹理参考（约 25 秒）
占成本的相当一部分。16 对 × 5 个预算 × 8 个变体的完整运行，Flux 3 Klein 用时 70 分钟，
MOSS-Image 用时 150 分钟；Anima 分两个阶段运行，分别为 57 分钟和 101 分钟。

## 评估协议

协议沿用早期工作，以保持数字可比。

- **模型：** Anima（flow-matching DiT），768×1024，cfg 5.0，`normal` 调度器；Flux 3 Klein
  （int8 检查点），768×1024，cfg 1.0，`normal` 调度器，FLUX.2 VAE（见下文 Flux 3 配置）；以及
  MOSS-Image SFT（int8 检查点），768×1024，cfg 3.0，`normal` 调度器，FLUX.2 VAE，Qwen3.5-9B
  文本编码器，负面提示词 `worst quality, bad anatomy`。MOSS-Image 原样使用 Anima 协议
  （100 步 `euler` 参考），池化为 4×。
- **预算：** 6、8、10、12、15 NFE，仅限每步 1 NFE 的采样器。
- **几何**（越低越好）：在潜空间做平均池化后，与参考之间的 RMS 偏差（Anima 为 8×）。对 Anima，
  参考为 100 步 `euler` 运行。
- **纹理：** 高通残差的 RMS（潜变量减去其 8× 池化版本）。同时给出绝对值以及与收敛参考（此处为
  30 步 `sa_solver`）的差距（早期工作对六个随机采样器取平均，因此绝对差距不能直接比较）。
- **提示词与 seed：** 沿用早期工作的四类提示词（flat、face、fur、grid），seed 数多于最初的 2 个，
  以便把差异与 seed 间的波动相比较。
- **Flux 3 配置。** 对 Anima 协议有两处刻意的偏离：
  1. *几何参考。* 对这个检查点，100 步 `euler` 运行**不是**收敛参考：ODE 在 10 步与 100 步的结果
     之间的差异，与互不相关的图像之间的差异相当（池化后 RMS：一个提示词为 0.51，另一个为 0.54；
     后者在 50 步与 100 步之间仅为 0.016），因为构图会随步数改变。这与步数蒸馏的检查点一致，
     但这是从采样行为推断的，而不是由模型说明确认的。因此几何以**相同步数和 seed** 的确定性
     `euler` 运行为参考来度量，即它是噪声造成的偏差，而不是相对某个极限的误差。Flux 3 的几何
     数值与 Anima 不可比。
  2. *池化。* FLUX.2 潜变量的空间下采样为 16× 而非 8×，因此池化取 4×，以保持相同的像素范围。
- **报告：** 给出均值及置信区间；只有当差异超过 seed 间波动时才宣称成立。负面结果也会报告。

**解读。** 没有稳健的效果。在 20 次比较（4 个变体 × 5 个预算）中，18 个区间包含零。不含零的两个
都在 6 NFE，且符号相反（`pce_m1` 为正，`curv_m1` 略为负，上界 −0.0001）；20 次未校正的检验中，
偶然出现一次这样的偏离是可以预期的。没有任何变体的符号在各预算之间保持一致，区间半宽从 6 NFE
时的约 0.002–0.008 增大到 15 NFE 时的约 0.02–0.03。

曲率假设在此处检验的形式下**未得到支持**：按局部曲率在任一方向上重新分配固定的噪声预算，在
Anima 的 6–15 NFE 下都没有改善相对于均匀 `eta` 的几何/纹理折中。唯一值得后续跟进的候选是最低
预算下的 `pce_m1`（+0.0084，约为 6 NFE 下均匀 `eta` 1.4–2.0 所覆盖纹理范围的一半），因为它是
唯一经得起自身区间检验的结果；要称其为真实，还需要更多样本。

注意事项：

- 只有一个 `eta_bar`（1.7）、`exponent = ±1`，权重被限制在 `[1/3, 3]`。更强的扰动、不同的基础
  `eta` 或不同的参考（`smoothing`）可能表现不同；均未尝试。
- n = 16 下的负面结果只能排除大于区间半宽的效应（按预算和变体不同，约 0.002–0.03 个纹理单位）。
- 绝对几何值约为早期工作中相同采样器所引用数值的 2.3 倍，但顺序（`euler` 差于 `sa_solver`）相同。
  两套代码的指标设置或参考很可能有变化；请勿跨两个仓库比较绝对数值。
- 10 步的 `ode` 仅作参考，位于前沿范围之外。
- 几何和纹理是潜空间中的代理指标，尚未用人类判断验证。
- 这些运行使用 ComfyUI 0.31.1。升级到 0.42.5（Flux 3 所需）后，确定性的 `euler` 输出逐位一致，
  但随机采样器在相同 seed 下产生不同的噪声实现，因此两个版本的 Anima 运行不可混用于同一配对
  比较。原因未做调查。

### Flux 3 Klein

设置：Flux 3 Klein int8 检查点，768×1024，cfg 1.0，`normal` 调度器，ComfyUI 0.42.5，4 类提示词
× 4 个 seed（16 个配对样本），预算为 6、8、10、12、15 NFE；约每步 0.65 秒。`eta_bar = 1.7`，
`exponent = ±1`，预算守恒。几何为相对相同预算 `euler` 运行的偏差（见协议）。

**相对均匀前沿的纹理优势**（点估计及 95 % bootstrap CI；`*` 表示区间不含零）：

| 变体 | 6 NFE | 8 NFE | 10 NFE | 12 NFE | 15 NFE |
| --- | --- | --- | --- | --- | --- |
| `curv_p1` | −0.0017 [−0.0023, −0.0011] * | −0.0025 [−0.0040, −0.0011] * | +0.0009 [−0.0009, +0.0029] | +0.0003 [−0.0024, +0.0031] | +0.0049 [+0.0003, +0.0096] * |
| `curv_m1` | +0.0045 [+0.0034, +0.0055] * | +0.0030 [+0.0012, +0.0051] * | −0.0043 [−0.0073, −0.0013] * | −0.0034 [−0.0058, −0.0013] * | −0.0049 [−0.0101, −0.0004] * |
| `pce_p1` | −0.0016 [−0.0021, −0.0012] * | −0.0041 [−0.0053, −0.0027] * | −0.0113 [−0.0151, −0.0074] * | −0.0084 [−0.0122, −0.0044] * | −0.0100 [−0.0142, −0.0058] * |
| `pce_m1` | +0.0041 [+0.0028, +0.0053] * | +0.0042 [+0.0034, +0.0051] * | +0.0090 [+0.0058, +0.0115] * | +0.0042 [+0.0016, +0.0065] * | +0.0110 [+0.0052, +0.0167] * |

**解读。**

- **基于误差的分配有一致的效果。** `pce_m1`（免费的预测器–校正器误差小时多加噪声，误差大时少加）
  在全部五个预算上都为正，且区间不含零；其镜像 `pce_p1` 在全部五个预算上都为负。这种剂量–反应
  关系很难用偶然解释。幅度不大：在 15 NFE，`pce_m1` 获得 0.0110 个纹理单位，约为均匀 `eta` 从
  1.4 增至 2.0 所换得纹理（0.7145 → 0.7268）的 90 %；在 10 NFE 约为该范围的一半。相对于纹理
  值本身（约 0.7）为 1–2 %。
- **曲率不是稳定的控制量。** `curv_m1` 在 6 和 8 NFE 为正，在 10、12、15 NFE 为负；`curv_p1`
  则相反。效应符号取决于预算，因此曲率规则的任何单一方向都不能在各预算上都有帮助。原先的曲率
  假设仍未得到支持；Flux 3 上的结果由误差信号承载。
- **分配规律不具通用性。** 同样的 `pce_m1` 设置在 Anima 上没有定论：6 和 10 NFE 的点估计为正，
  但都不可靠，其余预算符号不同。无论机制如何，它在这个模型上都明显强于 Anima，这样对迁移问题的
  回答是“需要按模型重新校准”，而不是“通用”。

针对此结果的注意事项：

- 纹理是潜空间中的高频能量。它无法区分真实的精细细节与残余噪声，而在轨迹后期加入的噪声同样
  会使其升高。对两个提示词、一个 seed 的 15 NFE 裁剪图做的抽查显示，`pce_m1` 相对均匀 `eta`
  没有明显的颗粒感，但抽查不等于检验。次要目标中列出的人类研究现在是信息量最大的后续实验。
- 几何轴的含义发生了变化（相对同预算确定性运行的偏差），且该检查点很可能经过步数蒸馏，因此
  前沿来自一个对 `eta` 的响应比 Anima 平坦得多的模型（10 NFE 下 `eta` 1.4 → 2.0，纹理
  0.7097 → 0.7274）。在平坦的前沿上，较小的绝对差异分量更重。
- 做了 20 次比较，未做多重检验校正。方向一致的 `pce` 模式不依赖于此，但孤立的显著 `curv` 区间
  可能依赖。
- 只有一个 `eta_bar`、一种 `exponent` 幅度、一个检查点。

### MOSS-Image

设置：MOSS-Image SFT int8 检查点，768×1024，cfg 3.0，使用普通 classifier-free guidance（不含
skip-layer guidance），`normal` 调度器，ComfyUI 0.42.5，4 类提示词 × 4 个 seed（16 个配对样本），
预算为 6、8、10、12、15 NFE；约每步 0.9 秒。`eta_bar = 1.7`，`exponent = ±1`，预算守恒。与
Flux 3 不同，该检查点未经步数蒸馏，100 步 `euler` 运行可作参考（50 步与 100 步之间的池化 RMS：
两个提示词分别为 0.16 和 0.05），因此原样使用 Anima 协议。官方建议至少 50 步和至少 1 MP；本实验
为 6–15 步和 0.79 MP，处于预期使用范围之外。

**相对均匀前沿的纹理优势**（`*` 表示区间不含零）：

| 变体 | 6 NFE | 8 NFE | 10 NFE | 12 NFE | 15 NFE |
| --- | --- | --- | --- | --- | --- |
| `curv_p1` | −0.0017 [−0.0028, −0.0007] * | −0.0021 [−0.0048, +0.0007] | −0.0036 [−0.0080, −0.0003] * | +0.0011 [−0.0025, +0.0040] | −0.0022 [−0.0091, +0.0041] |
| `curv_m1` | +0.0029 [+0.0015, +0.0042] * | +0.0015 [−0.0009, +0.0034] | −0.0029 [−0.0086, +0.0021] | −0.0045 [−0.0095, +0.0020] | −0.0029 [−0.0067, +0.0013] |
| `pce_p1` | +0.0003 [−0.0004, +0.0010] | −0.0020 [−0.0039, −0.0002] * | −0.0120 [−0.0185, −0.0063] * | −0.0106 [−0.0156, −0.0059] * | −0.0141 [−0.0211, −0.0069] * |
| `pce_m1` | +0.0004 [−0.0005, +0.0010] | +0.0033 [+0.0011, +0.0055] * | +0.0031 [−0.0004, +0.0068] | +0.0012 [−0.0035, +0.0061] | +0.0040 [−0.0015, +0.0091] |

**解读。**

- **误差信号只在一个方向上起作用。** 把噪声集中在预测器–校正器误差*大*的步上（`pce_p1`），
  在 8–15 NFE 下会在相同几何下损失 0.002–0.014 的纹理，五个预算中有四个的区间不含零。相反的
  选择（`pce_m1`）在每个预算上点估计都为正，但只有 8 NFE 显著（+0.0033）。这种不对称（损失
  约为收益的三到四倍）提示，有害的是把噪声注入到求解器本来就不准确之处，而把噪声挪到别处只带来
  很小的好处。这是对三组数据的解读，不是经过检验的机制。
- **在 6 NFE 时，分配几乎没有可重新分配的空间。** 此时 `pce_p1` 和 `pce_m1` 与均匀 `eta`
  几乎重合（几何 0.4862 和 0.4864，对比 0.4864），这符合噪声窗口只包含少数几步的预期。
- **曲率同样没有稳定效果。** 在 6 NFE 有两个显著区间，两个方向的符号相反，更高预算上没有一致
  的结果。

## 次要目标

- **迁移到另一个 flow-matching 模型。** 已对 Flux 3 Klein 完成（见上）：该效应不通用。MOSS-Image
  （不同架构：5B 参数的 DiT，Qwen3.5-9B 文本编码器，仅共用 FLUX.2 VAE）也已完成；`pc_error`
  效应的方向与 Flux 3 一致，但幅度小得多。
- **用人类判断验证指标。** 图像集和答案键已准备好（见[人类研究材料](#人类研究材料)）；尚未收集
  回答。该研究询问两张图像中哪一张看起来像 AI 生成，以检验自定义的几何和纹理指标是否与人类感知
  一致，因为所有定量结论都建立在这些指标之上。考虑到 Flux 3 的结果，这是优先事项：问题是人是否
  能察觉 `pce_m1` 带来的纹理增益。

## 已知局限

- 三个模型，其中两个使用 int8 检查点，且只有一个 `eta_bar`；Flux 3 配置使用的几何参考与另外两个
  不同。
- 几何和纹理是潜空间中的代理指标，而非经过验证的感知指标。
- 提高 `eta` 也会改变构图，因此相对于确定性参考的“几何”把结构性损伤与合理的变化混在了一起。

## 与早期仓库的关系

`sampler.py` 中的 SA-Solver 循环改编自 `adaptive-step-samplers` 的 `sample_adaptive_sa`，并把
误差驱动的控制器替换为 `NoiseAllocator`。轨迹探针和分析脚本未被复制，实验运行器也不依赖它们：
它使用核心的 `SaveLatent` 节点保存最终潜变量。
